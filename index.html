PROYECTO SOC / BLUE TEAM

Laboratorio de Seguridad SIEM & XDR

Monitoreo defensivo con Wazuh y Windows Server 2022 para detección de eventos en tiempo real, análisis de vulnerabilidades y FIM.

🖥️ Arquitectura del Lab

  • SIEM Manager: Wazuh v4.9 en Docker (Kali Linux).
  • Endpoint: Windows Server 2022 con Agente Wazuh.
  • Red: Entorno aislado en VirtualBox (10.0.2.0/24).

🚨 Detección de Autenticación

  • Auditoría activa de inicio de sesión.
  • Detección de intentos fallidos vía NTLM/SMB.
  • Ingesta del Event ID 4625 (Regla 18108).

🛡️ Integridad de Archivos (FIM)

  • Monitoreo en tiempo real del directorio C:\Monitoreo.
  • Captura de cambios mediante sumas SHA256.
  • Alarma instantánea bajo la Regla 550.

📊 Gestión de Vulnerabilidades

  • Cruce automatizado con base de datos CVE (NVD/MITRE).
  • Detección de parches críticos pendientes en el SO.
  • Identificación de fallos de ejecución remota en RDP.
